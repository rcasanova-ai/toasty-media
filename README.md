# Toasty Media

> **Colosseum judges: start with [`peeps/README.md`](peeps/README.md).** Clone, then `npm run demo` and open http://127.0.0.1:4173/peeps/demo/ (no install, no accounts, no wallet).

This repository contains the Toasty Media public website foundation and Toasty Studio, a browser-based interview and podcast studio.

- Public site: `site/`
- Studio director console: `studio/director.html`
- Studio guest join flow: `studio/guest.html`
- Shared brand assets: `shared/brand/`
- Shared CSS and JavaScript: `css/`, `js/`
- Architecture and roadmap: `docs/`

The current Studio MVP uses hosted VDO.Ninja through a local adapter. No deployment or push is performed from this repository without approval.
