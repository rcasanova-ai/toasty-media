Why "Generate/Test" is disabled

No zero-cost, in-session-testable path produced a genuinely convincing alternate camera angle — see the engineering comparison in this session's report. The honest options were: (1) a real neural reangle model (LivePortrait-class), which needs a GPU server Toasty doesn't currently have; (2) a paid real-time avatar API, which needs a signup/spend decision this spike isn't authorized to make; (3) browser-only face-mesh warping, which is buildable without cost but is a from-scratch rendering project, not a button click, and this page won't fake that result. This page stops at reference capture + the data model so the decision is informed, not guessed at.
